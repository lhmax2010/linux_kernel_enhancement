    mm: restore vendor reclaim semantics and enable zram backends
    
    The vendor memory.force_reclaim interface retained a boolean true after
    the reclaim API changed to option bits. Pass MEMCG_RECLAIM_MAY_SWAP so
    anonymous pages can be swapped out again, without adding proactive
    reclaim semantics.
    
    Honor the write_u64 callback contract by returning zero on success.
    Reject requests larger than ULONG_MAX, skip zero requests, request only
    the remaining target on each pass, and stop after two consecutive passes
    without progress. Keep the existing reclaim diagnostic. Reclaim batching
    may still overshoot the target; this is not a strict page cap.
    
    Enable the zstd and lz4 zram backends in both BCM2711 base defconfigs.
    Retain LZO explicitly and preserve lzo-rle as the default algorithm.
    Normal and RT builds share these base configs through the current
    configuration fragment layout. Multi-compression remains disabled.
