    linux-tizen-modules: require /usr/bin/find and drop coreutils in post scripts
    
    Post scripts call find, which can be provided by either findutils
    or toybox. Use file dependency /usr/bin/find instead of explicit
    package dependency, and remove coreutils dependency since POSIX sh
    and toybox provide required tools.
