Input: four task2 vmlinux, vmlinux.a (thin archive of final built-in link inputs), saved .o.cmd, final .config, and task2 nm/size/module evidence.
Tools: each buildroot usr/bin/{qemu-arm,readelf,size,nm,objdump,objcopy,clang-22}, or that same root emul/usr/bin binaries via its own emul/usr/lib64/ld-linux-x86-64.so.2 --library-path emul/usr/lib64. Host Python handles parsing/hashing/Markdown only. Host rpm --eval is used ONLY for the explicitly requested host dbpath audit, not artifact analysis.
readelf -SW vmlinux: debug if name starts .debug_; freed if SHF_ALLOC and (.init* or .exit.text); resident if SHF_ALLOC otherwise. All other sections retained as other, not lost from accounting. Sum logical sh_size, including NOBITS. No physical-page rounding.
size -A vmlinux.a: exactly one row per thin archive member; .text/.rodata/.data/.bss and dot suffixes included; .data..percpu excluded. Never recurse/sum parent built-in archives again. Group member directory to depths 1/2/4, independently. Final minus input is explicit linker residual, never allocated proportionally.
nm -S --defined-only: reuse task2 outputs from corresponding roots, filter T/t/W/w within final .text address range, normalize only .isra.N/.constprop.N/.part.N and sum each name group. New/removed names tracked separately; aliases and padding explain why symbolic totals differ from final .text.
objdump -dr object: blocks by symbol. For bl targets, R_ARM_CALL takes priority over displayed unresolved operand; if no relocation use local target in angle brackets. Final objdump -d -j .text: count decoded add/mov fp,sp, bl __gnu_mcount_nc, bl __stack_chk_fail, nop. No decoded instruction count is called CPU time or causal code saving.
Clang remarks: 4 separately emitted objects with original flags plus report flags, output/depfile mapped to temp. Compare extracted .text SHA256 to original via platform objcopy; all identical. Count Passed/inline/Inlined, Passed/loop-unroll/FullyUnrolled, Missed/annotation-remarks/AutoInitStore and explicit stack-protector remarks per function. Counts are optimization events, not bytes.
Causal bookkeeping: four audited objects net .text +390532 B. Outside those symbol name sets, extra frame-setup instructions (59969-1741)*4=232912 B. Remaining final text delta 1430936 B. These disjoint observation scopes are NOT six independently measured causal effects; same-name aliases and function transformations are limitations.
Kallsyms estimate: parse final .tmp_vmlinux2.kallsyms.S compressed name encoding and its symbol type, count non T/t/W/w entries; current encoded names +7 bytes/entry (offset+name-order index)+approximate marker savings. Shared token dictionary, changed compression and mandatory boundary filters are uncertain. No kernel rebuild.
All object estimates exclude unwind/BTF/kallsyms, source caller expansion, linked string merging, and runtime allocation. Group estimates overlap and must not be blindly summed.
